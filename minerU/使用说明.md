# MinerU PDF 解析插件 · 使用说明

> 版本 2.0.0 · 为 AI 精读（RaA）提供 PDF → Markdown 解析与缓存。

## 这个插件做什么？

当文献含**复杂公式 / 表格**、用内置解析不够时，可用 **MinerU** 把 PDF 转成高质量 **Markdown** 供 AI 阅读。本插件负责：

- 把解析好的 **md 按文献缓存**（再次打开同一文献直接命中，不重复解析）；
- 支持 **Agent 轻量**（免 token）与 **精准解析**（Token、公式识别）两种方式；
- 提供缓存**自动清理间隔**与**一键清理**。

## 第一步：安装

1. SgelinLog 导航栏「🧩 插件」→ 拖入 `minerU.zip`。
2. 点击插件名 → 打开设置面板（配置界面由插件自己显示）。

## 三种用法

打开要精读的文献 → 打开「🧩 插件 → MinerU PDF 解析」。

### 方式一：Agent 轻量（简单，免 Token）
1. 填 PDF 的网址（需可访问的 URL）；
2. 「生成提交命令」→ 复制，在电脑终端里执行；
3. 把返回的 `task_id` 粘回 → 「绑定并自动轮询」；
4. 完成后自动缓存 md，文献详情页出现「📄 md缓存」徽章。

### 方式二：精准解析（带公式文献，推荐）
1. 先在下方「⚙️ 设置」填 MinerU Token 并保存（默认 `vlm` 模型、公式识别已开）；
2. 填 PDF 网址 → 「生成精准提交命令」→ 在终端执行（命令已带 Token、公式开关）；
3. 在终端轮询任务直到完成，下载返回的 **zip**；
4. 解压出里面的 `full.md` → 用面板「③ 导入 .md」选择它 → 缓存完成。

### 方式三：直接导入已有 md
本地已有一份解析好的 md（任何来源），用「③ 导入 .md」缓存到当前文献即可。

## 缓存管理

- 打开已缓存的文献：详情页显示「📄 md缓存 · 来源 · 时间」。
- 设置「缓存自动清理间隔（天）」：超过该天数未使用的缓存会被自动清除；`0` = 不自动清理。
- 「🧹 一键清理全部缓存」「自动清理（按设置天数）」「删」单条删除 均可手动管理。
- 缓存文件在 `user_data/plugins/mineru-markdown/markdown/`。

## 常见问题

- **为什么提交要在终端做？** MinerU 提交接口是 POST 且需鉴权，插件沙箱只能发免鉴权 GET，故由插件生成命令、你在终端执行。
- **精准结果为什么是 zip？** MinerU 精准解析输出 zip（含 `full.md`）。插件无法自动解压，解压后导入即可。
- **显示「尚未配置 Token」？** 精准命令需要 Token，请先到设置填写保存。
- **显示查询失败/网络错误？** 检查网络；Agent 接口免 Token，精准接口请确认 Token 正确。

## 隐私与缓存安全

- 仅把**你填写的文件 URL / task_id** 发送给 mineru.net；本地文献内容只在「导入 md」时由你主动选择后才写入插件目录，不上传。
- Token 当前保存在本机插件配置中，不随软件自动上传；由于 V2.5.9 仍使用明文插件配置，请勿把 `config.json` 加入版本库、压缩包或问题截图。
- RaA 后台缓存使用 PDF 内容 SHA-256 识别源文件。同名但内容不同的 PDF 不会复用旧缓存；没有 `sourceHash` 的旧记录会在下一次解析时失效。
- 插件只能通过宿主权限访问自身缓存目录，网络请求必须声明 `network` 权限并经过宿主代理。
